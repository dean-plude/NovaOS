NovaOS 0.2 "Kepler" is the second release of NovaOS, the from-scratch
x86-64 operating system that runs native Windows programs: their own
machine code runs directly on the CPU, and NovaOS supplies the NT system
calls, the Win32 API, the loader, the desktop and the drivers they expect.
Where 0.1 proved that programs run, Kepler is the first release meant to
be lived in: it has accounts and sign-in, asks before a program runs as
administrator, comes back from a bad update, installs beside Windows and
prints.

This ISO passed every CI suite before it was published: the core,
network and device self-tests (including starting from this ISO) and the
OpenGL and Direct3D tests.

## What is new since 0.1

**Everyday use**

- **Accounts and sign-in.** Several accounts, a sign-in screen, standard
  and administrator users, fast user switching and an Accounts page in
  Settings.
- **UAC.** A program that asks for administrator rights shows a consent
  or credential prompt; `C:\Windows`, `C:\Programs` and the machine part
  of the registry cannot be changed by an unelevated program; processes
  carry integrity levels.
- **Updates that come back.** A new kernel that crashes, hangs or never
  reaches the desktop is replaced by the previous one on the next start
  (a hardware watchdog catches a hung start). The boot menu's **Advanced
  startup** offers the previous version, safe mode and startup repair, and
  Settings has **Reset this PC**.
- **Install beside Windows.** Setup shows the disk's partitions, installs
  into free space or shrinks Windows' NTFS volume to make room, adds a
  firmware boot entry, shows a boot menu that offers Windows, and
  reinstalls without touching drive C:.
- **Printing.** A print spooler, **Microsoft Print to PDF**, the Windows
  print dialogs, network printers over IPP and Settings > Printers;
  Notepad++ and SumatraPDF print in the app corpus.
- **Tools.** Task Manager, Device Manager, Disk Management, Event Viewer,
  Calculator, a camera app, and a new brand with wallpapers and icon sets
  that are files you choose in Settings.

**Windows drivers.** Real driver packages (`.inf`, `.sys`, firmware) run
unchanged on NovaOS's NT driver interface with Microsoft's KMDF, UMDF 2,
USB, NDIS, Storport and HID class support, matched by hardware ID and
fetched from the Microsoft Update Catalog under Windows' signing policy.
Intel's AX211 Wi-Fi driver loads and scans, a display-only WDDM driver runs
on the boot display, and cameras, game pads, touch screens and touchpads
work through the HID and UVC stacks.

**Games and graphics.** Direct3D 12 through VKD3D-Proton, GPU composition
for WebView2 and DirectComposition, Mesa's OpenGL built in, direct
presentation on QEMU's virtio GPU, and games from SuperTux and Cave Story
to Teeworlds and a Godot 4.7 Direct3D 12 game.

**More programs.** Firefox is the bundled browser, with LibreOffice,
Thunderbird, GIMP, Krita, OBS Studio, qBittorrent, WinSCP, ShareX and
.NET 8 desktop programs from the App Store, and DOS programs run through
an MS-DOS 4.0 built from Microsoft's source. The Windows Runtime pieces
under UWP and WinUI (Windows.UI.Core, Composition and the XAML core, which now has its
resource dictionary and object writer) are in progress.

**Laptop hardware (first parts).** Wi-Fi joins WPA2-Personal networks
(`netsh wlan connect name=SSID key=PASSPHRASE`, with a 4-way handshake
written for NovaOS) as well as open ones; a USB Bluetooth radio comes up,
pairs and runs a Bluetooth mouse through a host stack written from the
Core Specification; idle CPUs enter C-states with a stopped tick, and idle
devices go to D3, the first part of battery life. All three are checked
against modelled devices in QEMU, not yet on the T14.

**GPU groundwork.** A render driver's allocations get GPU virtual
addresses (`D3DKMTReserveGpuVirtualAddress` and its siblings), the third
part of the Intel GPU design; Intel's driver itself has not run yet.

**Hyper-V.** Keyboard, mouse, synthetic video, SCSI disks, network and the
integration services work against the VMBus implementation; they are
checked in CI against a model of Hyper-V, not yet on a real host.

[docs/compatibility.md]({blob}/docs/compatibility.md) lists every program
checked and how well it runs, and what common anti-cheat and DRM systems
require (NovaOS never bypasses them).

## Starting it

Check the download first: `sha256sum -c nova.iso.sha256` on Linux,
`shasum -a 256 -c nova.iso.sha256` on a Mac.

- **In QEMU** (Linux, macOS, Windows through WSL2): boot `nova.iso` on a
  q35 machine with UEFI firmware (OVMF) and 2 GB of memory; the
  [user guide]({blob}/docs/user-guide.md#trying-it-in-a-virtual-machine)
  has the command lines.
- **On a PC** with UEFI and Secure Boot off: write `nova.iso` to a USB
  stick (`dd`, Rufus in DD mode or balenaEtcher) and start from it.
- Started from the ISO, NovaOS runs live and offers **Install NovaOS**,
  on its own disk or beside Windows. The first start of the installed
  system asks for your name, time zone, keyboard layout and display
  resolution and creates the first account.

The [user guide]({blob}/docs/user-guide.md) covers the desktop, the App
Store, files, network and sound; [docs/building.md]({blob}/docs/building.md)
builds the same image from source.

## Updates

An installed NovaOS 0.1 or a newer build of `main` updates itself to this
release: the App Store's **Updates** page, or `update` in the Terminal,
reads this release's `novaos-update.txt`, installs the new kernel and boot
loader, and goes back to the old ones if the new kernel does not reach the
desktop ([docs/updates.md]({blob}/docs/updates.md)).

## Known limits

- NovaOS is developed and tested in QEMU. The reference PC, a Lenovo
  ThinkPad T14 Gen 4 (Intel), passed its first hand checks on 2026-10-15,
  but its Wi-Fi, Bluetooth, camera, power management and GPU have not been
  checked on the machine itself and a boot of this ISO on it has not been checked;
  [docs/hardware.md]({blob}/docs/hardware.md) says what has been verified.
  Other PCs are untested.
- 3D runs on the CPU (llvmpipe, lavapipe) except in QEMU's virtio-gpu
  with Venus; there is no driver for a real GPU yet.
- Wi-Fi (open and WPA2-Personal; no WPA3 or enterprise networks) and
  Bluetooth (a mouse, no headset audio yet) are tried against modelled
  devices only; no Secure Boot.
- Hyper-V has not been tried on a real host; the Update Catalog, Steam and
  GOG Galaxy sign-in are checked by hand only.
- Games whose anti-cheat makes its own system calls, such as Roblox's
  Hyperion, stop at start
  ([docs/compatibility.md]({blob}/docs/compatibility.md#roblox-and-anti-cheat)).
- Update channel files are not signed yet; they are checked by size,
  SHA-256 and version only.

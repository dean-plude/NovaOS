NovaOS 0.2.3 "Nebula" is the fifth release of NovaOS, the from-scratch
x86-64 operating system that runs native Windows programs: their own
machine code runs directly on the CPU, and NovaOS supplies the NT system
calls, the Win32 API, the loader, the desktop and the drivers they expect.
Nebula makes Store apps feel installed rather than started from a
terminal, gives XAML pages text input, runs a real vendor display driver
unchanged, and adds enterprise Wi-Fi and deeper idle power states.

## What is new since 0.2.2

**XAML text input.** A windowless Rich Edit underneath XAML's text boxes,
built in eight parts: the text services (`WinUIEdit.dll`, behind
`msftedit.dll`'s and `riched20.dll`'s `CreateTextServices` too) with
typing, selection, undo and redo and the clipboard; the Text Object Model
(`ITextDocument2`, ranges and a selection) with Direct2D drawing; a
`TextBox` on a XAML page that takes typing and a click, built from
Microsoft's MIT sources and drawn with DirectWrite; and `PasswordBox` and
`RichEditBox` (its `Document` is the Text Object Model), with select all,
cut, copy and paste through the clipboard checked in CI; and rich text's
character formats (bold, italic, underline, strikethrough and colour, from
Ctrl+B, I and U and from `CharacterFormat`); and a right-click menu on
the text boxes (Cut, Copy, Paste, Undo, Redo and Select All, from the
right button or the menu key) on `Windows.UI.Popups`' `PopupMenu`; and
paragraph alignment (a `TextBox`'s `TextAlignment`, a `RichEditBox`'s
paragraphs from Ctrl+L, E, R and J and `ParagraphFormat`); and paragraph
indents, hanging ones too (`ParagraphFormat.SetIndents`). WinUI's text
command bar flyout, font sizes and paragraph spacing in rich text and the
touch keyboard's input scope are not in yet.

**Packaged apps in the shell.** An installed package's apps appear in the
Start menu with their display name and tile logo from the manifest and
start from there; **Settings > Apps** lists packages and uninstalls them.
A packaged app whose window is minimised goes to the background and is
then suspended (its threads frozen, `Suspending` handlers given up to five
seconds), and is resumed when its window is restored.

**A vendor display driver, unchanged.** Red Hat's `viogpudo.sys` from the
virtio-win package, an unmodified Microsoft-signed WDDM driver, installs by
hardware ID on QEMU's virtio-vga and drives the display through NovaOS's
`dxgkrnl.sys` stand-in; Settings changes its mode and disabling it gives
the screen back. This is the check Intel's driver faces on the T14, done
first on hardware CI has.

**Wi-Fi enterprise networks.** WPA2-Enterprise with PEAP and MS-CHAPv2,
EAP-TLS with a certificate from `certutil -importpfx` (kept across
restarts, removed with `certutil -delstore`), and WPA3-Enterprise, joined with
`netsh wlan connect` or `wlanapi.dll` profiles. Checked against the devices
suite's modelled access point; the T14's own card is still unchecked.

**Deeper idle.** Windows drivers' runtime power management through the
power framework (PoFx components moved to their deepest state and back),
and `_LPI` low-power idle states, shown in the devices suite's `kmdfedu`
and `laptop` boots, ready for the idle-drain measurement on a real
laptop.

**Network List Manager.** `netprofm.dll`'s `INetworkListManager`,
`INetworkCostManager` and their events, so programs can ask whether they
are online, on which kind of network and whether it is metered; changing a
network's category goes through the firewall.

**Windows Calculator, continued.** Pulsar's slices continue: its page now
gets through menus and further XAML classes. It does not compute yet (see
below).

**Fixes.** A window embedded in another process's window keeps its place
(a race between the position and the embed message); the
`smpstress` file-access test measures a steady figure.

[docs/compatibility.md]({blob}/docs/compatibility.md) lists every program
checked and how well it runs.

## Starting it

Check the download first: `sha256sum -c nova.iso.sha256` on Linux,
`shasum -a 256 -c nova.iso.sha256` on a Mac.

- **In QEMU** (Linux, macOS, Windows through WSL2): boot `nova.iso` on a
  q35 machine with UEFI firmware (OVMF) and 2 GB of memory; the
  [user guide]({blob}/docs/user-guide.md#trying-it-in-a-virtual-machine)
  has the command lines.
- **In Hyper-V**: a Generation 2 virtual machine with Secure Boot off
  ([docs/hyperv.md]({blob}/docs/hyperv.md)).
- **On a PC** with UEFI and Secure Boot off: write `nova.iso` to a USB
  stick and start from it.
- Started from the ISO, NovaOS runs live and offers **Install NovaOS**.

## Updates

An installed NovaOS 0.2 or newer updates itself to this release from the
App Store's **Updates** page or with `update` in the Terminal
([docs/updates.md]({blob}/docs/updates.md)).

## Not finished

- **Windows Calculator does not compute yet.** Roadmap step 32.6 and Phase
  32 close when it does.
- **Signed updates** (23.5): needs the release key pair, which only the
  repository owner can make; until then update channel files are checked by
  size, SHA-256 and version only.
- **Not checked on the T14 or other real hardware:** Wi-Fi (including
  enterprise), Bluetooth, camera, idle power, the Intel GPU and a second
  monitor (23.2, 25.3 to 25.5, 28.1 to 28.4), a Hyper-V Generation 2 boot
  (23.4), store sign-ins (24.1, 24.2, 24.6) and Roblox (24.5). A second
  reference PC (28.5, an AMD machine) is not chosen.
- XAML's own `Application.Suspending` is not built yet; `CoreApplication`
  apps suspend and resume.
- The Network List Manager has no `IDispatch` interface, handles one
  adapter, and has no "Unidentified network".
- 3D runs on the CPU except in QEMU's virtio-gpu with Venus; anti-cheat
  games such as Roblox's Hyperion stop at start.
